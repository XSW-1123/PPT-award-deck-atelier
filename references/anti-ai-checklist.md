# 去 AI 味自查 · 水印体检 · 逐页目检

## 1. 「AI 味」的七个来源（按危害排序）

| # | 来源 | 替换方案 |
|---|---|---|
| 1 | 整片 corporate blue / 深蓝底 + 深蓝框 | 暖象牙 + 暖炭墨 + 铜褐三色，深色页 ≤ 7/15 |
| 2 | 蓝紫渐层 + 深色背景 | 砍渐层，指定低饱和色码 |
| 3 | 纯色矢量大色块、每页一枚几何徽标 | 贴题真实摄影 + 局部渐变蒙版 |
| 4 | 所有页同一个卡片模板 | 至少混合 3 种视觉处理，八页八种主件 |
| 5 | 高饱和亮金 + 宝蓝渐变「质感」 | 纯哑金 / 铜褐，去掉渐变高光 |
| 6 | 白胶囊标签、英文装饰行、自曝评分点话术 | 删；改用内容短句 |
| 7 | 朦胧背景被深色玻璃盖住（等于没加） | 把蒙版烘焙进 JPG，罩层降到 0.10–0.12 |

行业对标结论（2026）：`Corporate blue with flat grey` 已被 INK PPT 列入「What Is Completely Dead in 2026」；
`Real beats generated`（自有摄影 / 真实截图 / 真实文档 > 生成图）；
`Imperfection as Trust`；`Editorial Aesthetics`。
竞赛侧：主色 ≤ 3、字体 ≤ 2、留白 ≥ 30%、每页文字 < 300 字、板块间必有过渡句、图片要与目标职业相关。

## 2. 去 AI 味落地顺序

1. 真实摄影按页选图（贴内容，不用通用风景），目视确认无水印 / 无叠字 / 无角标署名；
2. 把「模糊 + 降饱和 + 暖调统一 + 方向渐变压暗」烘焙进 JPG；
3. SVG 只留 0.10–0.12 极淡玻璃罩；
4. 全局 hex 映射去蓝（自检 `B > R + 8` 的偏蓝色数量 = 0）；
5. 深色页从 10/15 减到 7/15，只剩仪式页；
6. 删白胶囊 / 英文装饰行 / 「对应评分项 XX 分」；
7. 罗盘底盘改半透明烟灰、扇区降饱和、渐变金换纯哑金；
8. 加固定刻度环让旋转「有参照物」，观感更像机械仪表而非生成图标。

同时检查：

| 项 | 期望 |
|---|---|
| `docProps/core.xml` 的 `dc:creator` | 空 |
| `lastModifiedBy` | 空 |
| `Application` | `Microsoft Office PowerPoint` |
| PPTX 内嵌图片 EXIF / PNG info | 0 条可疑元数据 |
| 源素材目录 EXIF / PNG info | 0 条可疑元数据 |
| 图片画面 | 无角标署名、无生成器水印、无叠字 |

**若命中为 0，不要「为了保险」删除任何可交付内容**——实测多次都是 0 命中，

若确有命中，只处理命中的具体对象，并把被弃用的合成底图保留供历史脚本复现，不做全目录删除。

## 4. 逐页目检清单（渲染后必须人工看）

自动门禁只看结构，看不出下面这些。**必须渲染全页 PNG + 总览 JPG 逐页目视**。

| 类别 | 具体要找 |
|---|---|
| 文字 | 贴边半截字、首字被裁、大数字下伸部穿字、行首孤立标点、深色页浅字看不清、章节页副标题被亮天空吃掉 |
| 背景 | 白雾带、白色扇形（浅色渐变盖深底）、云纹像脏水印、过曝白斑、夜景发黑成脏点 |
| 色块 | 页脚 16×3 小金块像脏点、未点亮格子消失、卡片透出不同底色、镂空蒙版方块感 |
| 图形 | 圆盘透明内环透出背景、扇区边缘锯齿、曲线无坐标轴不可读、图例压线、标注指向线横穿全图 |
| 版式 | 左右大块空白（如两侧各空 380 px）、卡片下半空 120 px、行宽与标题带不齐 |
| 一致性 | 八页是否其实同一个模板、仪式符号是否出现在内容页、深色页是否连成一大片 |
| 可读性 | 缩略图下主标题是否还读得出、数字与单位是否分离、进度轨刻度是否成脏点 |

### 目检方法

- **不要靠缩略图肉眼估坐标**。1280×720 在预览里被缩放会误判边界。
  正确做法：解析 SVG 里所有非 decoration 组的 `data-pptx-bounds` 取 `x+w` 最大值，
  或用 PIL 扫指定行的暗像素 run 反查文字实际 x 范围。
- 放大裁剪复核关键页（圆盘中心字、大数字、圆形遮罩、章节页文字）。
- 每轮修改后重新渲染、重新目检，不要累积未验证的改动。
