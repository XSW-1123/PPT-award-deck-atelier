# 负面案例库：v18–v27 全部被否方案与教训

> 动手前快速扫一遍。这里每一条都是真实被用户否决、或目检发现硬伤后撤销的做法。

## A. 被用户明确否决的设计

| 版本 | 做法 | 用户原话 / 诊断 |
|---|---|---|
| v19 | 把罗盘 / 仪表盘搬到全部 8 张内容页 | 「我是让你学习目录那样的，但没让你完全一样呀，都是这种旋转圆盘，那不重复了吗，很难看呀」 ⇒ 仪式符号复用过度，符号被用废 |
| v21→v22 | 8 张内容页全是浅纸白底 + 小色块，互不相干 | 「内容页还是很一般」 ⇒ 缺少大面积深色高对比主视觉，缺少贯穿全篇的母题，八张独立海报 |
| v22→v23 | 同一个「测绘图集」模板套满八页 | 「内容页一般」 ⇒ 项目 `spec_lock` 早就锁了「每页版式不重复」；图签 / 比例尺 / 等高线是装饰底纹，不承载信息 |
| v23→v24 | 封面右侧大罗盘常驻 | 「最后翻页的时候出现就可以了」 ⇒ 改为封面隐形指针 + 结尾收束罗盘 |
| v24→v25 | 15 页 15 张不同底图，只配对一根 48px 小指针 | 「转换还是有点不丝滑」 ⇒ 背景没锁死，带不动整页，其余全淡入淡出 |
| v26 | 深蓝灰 + 整片蓝底 + 朦胧背景被 0.64/0.74 玻璃盖住 | 「AI 味太重」「配色和样式都很 AI」「很多页全是蓝色背景底色」「朦胧背景呀」 ⇒ 背景等于没加 |
| v26 | 用户打开的是正式名旧版 v25 | 同一组投诉连续两轮 ⇒ 交付后没确认正式文件名是最新版 |

## C. 工程踩坑

| 坑 | 对策 |
|---|---|
| `order: 0` 被 `animation_config.py validate` 拒绝 | 必须是正整数，从 1 开始 |
| 先 validate 后生成 SVG → `references a missing group` | 先生成 15 张 SVG，再写 / 校验动画 |
| 导出 `svg_to_pptx.py` 传了 `-t` / `-a` | 会覆盖 sidecar，全部 Morph 丢失；**绝不传** |
| 章节页中心 100px 字重复 4 次触发 typography recurrence | `spec_lock.md ## typography` 加 `- dial_core: 100` |
| 巨型水印超 viewBox 2px | 上移 + 声明字号 |
| 导出前没重跑 `--json` | `default release export requires a passing final SVG quality report` |
| `animation_config.py` 单独跑报相对导入错 | 以 `svg_to_pptx.py` 内部校验为准 |
| 顶层 `<g>` 子元素全是图元 → 旋转被烘焙、组 `rot=0` | 组内放一个 `<text>`，走 `rotate_pivot` fallback |
| `transform` 带 translate/scale → `rotate_pivot=None` | 只用纯 `rotate(angle cx cy)`，pivot = 组 bbox 中心 |
| `stage` 组 bounds 写成整张画布不变 | PPT 认为没动，Morph 不插值；逐页变化 |
| 复杂 freeform 让 Morph 中途跳形 | Stage 组内只用原生 `<rect>` |
| `clip-path` / `<mask>` / `<polyline>` / `stroke-dasharray` / `<pattern>` / `<path A>` | 转换器拒绝；预烘焙 PNG 或用离散点 / 短 line / 手画 |
| 补丁 `old` 字符串尾随空格导致静默失配 | 每次 `assert s.count(old) == 1` |
| 重写八页漏 `P0X = p` 与 `</svg>` 闭合 | 正则批量补齐后逐页 XML 解析验证 |
| Word `doc.SaveAs(pdf, FileFormat=17)` 命令失败 | 用 `doc.ExportAsFixedFormat(OutputFileName=..., ExportFormat=17)`，先移走旧 PDF |
| 雪山 / 云纹照片 0.09 透明度在纸白区像脏水印 | 改矢量极淡方格 0.045 |
| 深色底盖浅色渐变 = 漏光 | 禁止 |
| 正式 PPTX 被独占句柄锁住 | 三级降级覆盖；备用名落地；锁释放后立刻补覆盖正式名并同步备用名 |
| Git Bash 里 `icacls /grant` 被 MSYS 转路径 | `MSYS2_ARG_CONV_EXCL='*'` |

## D. 方法论层面的教训

1. **「学习惊艳程度」≠「复制同一个图形」**。用户要的是同一级别的视觉冲击力，不是同一个母题。
2. **统一靠线索，不靠模板**。底图 / 顶栏 / 页脚 / 书脊 / 进度轨锁死；主件每页不同。
3. **先查是不是旧文件，再改设计**。重复投诉时优先核对文件大小与 media 数。
4. **把旋转写进静态页面序列**，不要只押在动画上：即使动画不触发，翻页也能看到盘转了一格。
5. **装饰不承载信息就不画**。图签、比例尺、等高线被否，正因为它们好看但不说事。
6. **只改用户否定的那一层**。配色被否就换配色，别把整本推倒重来。
7. **每次都要渲染 + 目检**。自动门禁 0 error 不等于好看；白雾、半截字、过曝只有人眼看得出。
8. **联网对标要落在可执行的参数上**（具体 hex、具体方向、具体占比），不要只写「要高级」。
