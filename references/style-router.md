# 风格路由：从用户描述自主选风格

> 本文件是技能的核心决策表。目标：把一段自然语言需求，转成**唯一、可执行、可解释**的视觉方案，
> 而不是每次都套同一个模板。

## 1. 抽取信号

从用户原话中打标。一句话可能同时命中多列，按「约束 > 情绪 > 场合 > 结构 > 素材」优先级取交集。

| 信号组 | 关键词示例 | 映射到的决策 |
|---|---|---|
| **硬约束** | 旋转到每个主题、圆盘、丝滑、平滑、不要常驻、最后才出现、朦胧背景、不要 AI 味、别全是蓝底 | 仪式母题形态 + 转场方案 + 配色禁用 |
| **情绪** | 惊艳、高级、拿第一、遥遥领先、沉稳、克制、温暖、科技感 | 对比强度、深色页占比、主件尺度 |
| **场合** | 竞赛答辩、生涯规划、金奖、路演、汇报、发布、教学 | 页数骨架、内容审核严格度、动效强度 |
| **结构** | 四章、15 页、成长路径、有数据、证据链、复盘 | 仪式母题数量、内容主件类型 |
| **素材** | 有真实摄影 / 有品牌色 / 只有截图 / 无图 | 是否启用朦胧背景、是否允许图形化底纹 |

### 默认假设（用户没说时采用，并在回复里写明）

- 画布 16:9，1280×720 SVG 坐标；
- 页数 = 封面 1 + 目录 1 + 章节页 N + 内容页 2N + 结尾 1（N=4 时正好 15 页）；
- 主色 ≤ 3，标题 / 正文两类字体 + 一个数字衬线体；
- 全书 1 个仪式母题 + 1 个内容母题，二者几何不同构；
- 转场用 Morph 0.9s，首页 fade 0.55s；
- 除非明确要求「克制」，否则默认走「惊艳」档：深色仪式页 + 大字号内容页。

## 2. 主决策表

先按**场合 + 硬约束**锁定行，再用情绪微调。

| # | 触发组合 | 选用预设 | 仪式母题 | 内容母题 | 转场 |
|---|---|---|---|---|---|
| R1 | 竞赛 / 答辩 / 成长叙事 + 要旋转 + 要丝滑 + 去 AI 味 | `S1 warm-editorial-compass` **（默认推荐）** | 固定外圈 + 真旋转转子 | 编辑式证据大版面 | Morph 三对象 |
| R2 | 竞赛 / 庄重 / 传统仪式感，未提去 AI 味 | `S2 navy-gold-compass` | 深蓝金四等分罗盘 | 信息图主件 | Morph 三对象 |
| R3 | 工程 / 技术 / 测绘 / 调研 / 数据密集 | `S3 survey-atlas` | 四段方刻度 | 图纸板内 8 种视图 | 板面横向滑移 |
| R4 | 「一页一个图」「雷达 / 仪表 / 对比」 | `S4 blueprint-infographic` | 顶栏徽标 | 8 种信息图 | 淡入 + 局部 Morph |
| R5 | 人文 / 柔和 / 朦胧 / 真实感优先 | `S5 photo-editorial-haze` | 极简指针 | 圆形遮罩 + 柔影卡片 | Morph 三对象 |
| R6 | 科技 / 发布 / 沉浸式 / 深色 | `S6 dark-cinematic` | 光晕 + 单点指针 | 巨数 + 大留白 | zoom & pan |
| R7 | 咨询 / 商务 / 克制 / 少即是多 | `S7 swiss-minimal` | 无（进度条代替） | 严格网格 + 大标题 | fade |
| R8 | 「还要更惊艳」「比上次更强」「长篇多章节」 | `S8 mixed-showstopper` | 罗盘 + 花瓣底纹 | 编辑式 + 图纸纹理混合 | Morph 三对象 + 局部深度推进 |

### 情绪微调规则

| 情绪词 | 调整 |
|---|---|
| 惊艳 / 拿第一 | 深色仪式页占比 45–50%，主件占版面 ≥ 40%，超大字号 96–166 px |
| 高级 | 降饱和、去渐变高光、加真实摄影、去掉所有胶囊标签与英文装饰行 |
| 克制 | 深色页降到 ≤ 20%，动效只留 fade，主件改线性图表 |
| 温暖 | 配色切暖象牙 / 暖炭墨 / 铜褐，禁用蓝相 hex |
| 沉稳 | 增大留白到 ≥ 40%，减少锐角与斜线 |
| 科技感 | 允许细网格与刻度，但**禁用蓝紫渐层**（最大 AI 雷区） |

## 3. 组合禁忌（命中即换方案）

| 禁忌 | 原因（真实否决 / 行业结论） |
|---|---|
| 圆盘/罗盘出现在内容页 | 用户：「都是这种旋转圆盘，那不重复了吗，很难看呀」 |
| 同一母题模板套满所有内容页 | 用户：「内容页还是一般」；项目 `spec_lock` 锁了「每页版式不重复」 |
| 八页互不相干的独立海报 | 缺少贯穿全篇的视觉线索，翻页没有连续感 |
| `Corporate blue + flat grey` | INK PPT《Presentation Design Trends 2026》列入「What Is Completely Dead in 2026」 |
| 蓝紫渐层 + 深色背景 | 最大 AI 生成痕迹；penchan 2026 明确点名 |
| 每页一枚几何徽标 / 纯色大色块 | 典型模板味；真实摄影 + 局部蒙版才是解药 |
| 深色底上盖浅色渐变做过渡 | 会形成横贯半页的白雾 / 白色扇形，像漏光脏点（实测负收益，已撤销） |
| SVG 里直接写 `clip-path` / `<mask>` | `svg_to_pptx` 明确拒绝，导出失败 |
| 页面上写「对应评分项 XX 分」「本页得分」 | 自曝评分点，模板话术，评委观感差 |
| 封面常驻大圆盘 + 结尾没有收束 | 用户：「最后翻页的时候出现就可以了」 |

## 4. 选型输出格式

S1 结束时必须产出下面这张表，先给用户确认再写码（用户已授权直接执行时可跳过确认，但仍要在回复里给出）：

```
场合 / 情绪 / 结构 / 硬约束 / 素材    → 抽取结果
选用预设                             → S1 warm-editorial-compass
排除                                 → S2（蓝相 AI 味）、S3（上轮已被否）、S4（圆盘复用）
仪式母题                             → 固定外圈 + 真旋转转子，仅 P02/P03/P05/P08/P12 + P15 收束
内容母题                             → 编辑式证据大版面，八页八种主件
配色                                 → #F3EFE6 / #2C2A26 / #9C7746
字体                                 → STXingkai（标题） / Microsoft YaHei（正文） / Georgia（数字）
转场                                 → 14 页 Morph 0.9s + 首页 fade；!!Stage / !!DialRotor / !!Rail
页数骨架                             → 15 页，深色页 7 页
每页主件                             → P04 巨数证据 / P06 四列岗位卡 / ...
```

## 5. 迭代时的路由规则

用户否定当前方案后，按「否定的对象」定向换层，**不要把整本推倒重来**：

| 用户否定的对象 | 换什么 | 保留什么 |
|---|---|---|
| 配色 / 色调 | 换整套配色，全局 hex 映射 | 版式、母题、转场、内容 |
| 「全是同一个图形」 | 换内容母题 | 仪式母题、统一线索、转场 |
| 「内容页一般」 | 换内容母题 + 加大主件 | 仪式母题、配色 |
| 「转场生硬」 | 锁死背景 + 增加强制配对对象 | 全部视觉 |
| 「朦胧背景没效果」 | 把蒙版烘焙进 JPG，降低罩层不透明度 | SVG 结构、动画 sidecar |
| 「AI 味重」 | 真实摄影 + 暖中性三色 + 删装饰话术 | 信息架构 |

> **关键教训**：用户连续两轮重复同一投诉时，先怀疑「他打开的是不是旧文件」，
> 用文件大小 / media 数量核对正式文件名，再考虑改设计。
