## S1 · `warm-editorial-compass` 暖调编辑·罗盘（默认推荐 / 最终版）

**适用**：竞赛答辩、成长叙事、既要旋转仪式又要去 AI 味、要求「高级、真实、惊艳」。
**来源**：v27，用户连续 10 轮迭代后通过目检的版本。

### 配色（三色，零蓝相）

```python
PAPER  = '#F3EFE6'   # 暖象牙，浅底
DEEP   = '#2C2A26'   # 暖炭墨，深底 / 标题字
GOLD   = '#9C7746'   # 铜褐，唯一强调色
GOLD_D = '#6B4E28'   # 深金，浅底小字
GOLD_L = '#C3A36E'   # 浅金，深底反白
GOLD_W = '#F0E6CE'   # 暖白，深底正文
SOFT   = '#A8A399'   # 暖灰，次要文字
BODY   = '#33312D'
MUT    = '#615D55'
LINE   = '#DCD5C7'
RED    = '#9E5340'   # 仅用于「差距」
GREEN  = '#4A6B52'   # 仅用于「已达成」
SMOKE  = '#33302A'   # 烟灰玻璃面板
DARK_PAGES = {1, 2, 3, 5, 8, 12, 15}   # 7/15 深色页，其余浅底
```

自检：全本 hex 里 `B > R` 的偏蓝色数量必须为 **0**。

### 骨架

- 封面 / 目录 / 4 章节 / 结尾 = 深色仪式页；8 张内容页 = 浅底；
- 全书统一：锁死的朦胧摄影底图 + 极淡方格（0.045）+ 深烟灰页脚带 + 书脊 + 进度轨；
- 仪式母题只在 P02 + 4 章节页出现大罗盘；封面**不放大盘**，结尾用 `closing_dial()` 收束；
- 顶栏 64px 小转子全书存在（含固定 12 刻度环），承担逐页旋转线索。

### 真实摄影选图原则

按**每页内容**选，不用通用风景。工程师岗就放工位 / 代码 / 机柜 / 电路板 / 大屏 / 真实校门 / 纸纹；
章节页用雾松 / 日出 / 夜景表达语义。所有图目视确认无水印、无叠加文字。

### 朦胧背景（必须烘焙进 JPG）

```python
WARM = (243, 238, 228)
INK  = (40, 36, 32)
# 深色页：blur 3.5 / 饱和 0.58 / 亮度 0.98 / 对比 0.92 / blend WARM 0.14
# 浅色页：blur 7.0 / 饱和 0.42 / 亮度 1.06 / 对比 0.78 / blend WARM 0.46
# 再用方向渐变蒙版 composite 到 INK
VEIL_CFG = {
    'ceremony_left_text':  ('R', 0.05, 0.84, 1.4),  # 文字在左 → 左深
    'ceremony_right_text': ('L', 0.05, 0.84, 1.4),  # 文字在右 → 右深
    'content':             ('V', 0.04, 0.50, 1.0),  # 内容页上浅下深
}
```

SVG 里只留 `fill-opacity="0.10"`（深）/ `0.12`（浅）的烟灰玻璃罩。
**v26 的失败**：玻璃 0.64 / 0.74 把背景整片盖住，朦胧背景等于没加。

### 渐变方向语义（写反会吃掉白字）

- `L` = 左浅右深；`R` = 左深右浅；`V` = 上浅下深；
- 封面 / 结尾文字在左 → `R`；目录 / 章节页文字在右 → `L`；内容页一律 `V`；
- 日出等最亮的章节页 `hi` 提到 0.90，左侧深字页 `hi` 只给 0.48–0.50。

### 反面案例

不可在本预设里回退到深海军蓝 / 亮金渐变 / 白胶囊标签 / `对应评分项` 话术。

## S2 · `navy-gold-compass` 深蓝金·罗盘（v18 / v23）

**适用**：庄重的传统仪式、校庆 / 政务 / 正式答辩，用户未提「去 AI 味」。
**注意**：2026 年起 corporate blue 已被行业列为过时，仅在用户明确要「庄重蓝金」时使用。

```python
DEEP='#0B2447'; GOLD='#A87C2E'; GOLD_D='#754D0B'; GOLD_L='#D8B267'
GOLD_W='#F5E7C4'; PAPER='#FBFAF7'; SOFT='#A9C0DC'
BODY='#2B3745'; LINE='#E4E9F0'; RED='#B04A32'; GREEN='#2C7A5A'
```

- 罗盘几何：`cx,cy = 400,376`；`r_out,r_in,r_mid = 230,158,194`；外圈 24 格刻度；
- 四扇区用 `arc_poly()` 离散点生成 `<polygon>`，**不用 `<path d="A...">`**；
- 四张章节页旋转 0 / -90 / -180 / -270，12 点指针固定、中心书法字固定；
- 即使动画不触发，翻页也能看到「盘转了一格」——把旋转写进静态页面序列是这版最大的价值。

## S3 · `survey-atlas` 测绘图集（v22）

**适用**：工程 / 技术 / 测绘 / 调研类，用户要「类似圆盘的惊艳但不是圆盘」。
**核心**：开敞斜向流动的等高线（有机曲线，与同心圆不同构）+ 统一图纸板。

```python
SH_BG='#071B36'; SH_GRID='#1B3D6B'; SH_GRID2='#2C5789'
SH_GOLD='#D8B267'; SH_WH='#E8F0F8'; SH_DIM='#829FBF'
SH_RED='#D4684A'; SH_OK='#9CC4AE'
```

- 图纸板 520×470、26px 网格、19 条等高线（每 4 条加粗为计曲线）、`phase` 逐页 0.0/0.7/…/4.9；
- 每页都有：图签 `SHEET 04 / 1:200`、四角裁切角标、比例尺、指北针、尺寸线（45° 端划 + knockout 标签）、引出线；
- 板内八种视图：控制网 / 地层剖面 / 设计线 vs 实测线 / 水准点 / 路线导线 / 方格网差值 / 偏航改线 / 纵断面；
- 左右交替放板，产生翻页节奏；
- 转换器不支持 `<polyline>` / `stroke-dasharray` / `<pattern>`：等高线用 `<path d="M… L…">`，虚线拆成短 `<line>`。

**被否原因**：八页同一个图纸模板套八次，且等高线 / 比例尺 / 图签是装饰底纹不承载信息。
⇒ 若要复用本预设，必须让每页板内视图承担**不同的真实信息**，并与其他母题混用。

## S4 · `blueprint-infographic` 蓝图信息图（v19 / v21）

**适用**：数据密集、「一页一个信息图主件」被明确点名。
**八种主件**（骨架互不相同）：

| 页 | 主件 |
|---|---|
| 自我认知 | N 刻度位次仪表（中心 `1/N`）+ 竖向刻度年表 + 证据条 |
| 岗位认知 | 四段箭头职责阶梯带 + 状态环 + 5 格刻度条 |
| 人岗匹配 | 四象限职责轮（3 实 1 空，中心 `3/4`）+ 三行缺口对比卡 |
| 学业 | 四联半圆仪表 + 课程条 + 错落证据墙 |
| 项目 | 里程碑 ribbon + 罗马数字刻度 + 节点卡 |
| 能力 | 六维雷达（金轮廓 = 基线，深蓝实填 = 现状）+ `3/6` 达成环 |
| 复盘 | 四段闭环（执行→复盘→判断→调整）+ 中心书法字 |
| 规划 | 主干三级阶梯 + 三条分支风险路线 |

- 配色收敛：已做 = 深蓝、部分 = 金、没做 = 红（空心），主色 ≤ 3；
- 公共几何 helper：`polar()` / `arc_poly()` / `tick_lines()` / `needle()`；
- **反面案例**：v19 把罗盘也搬到内容页做顶栏徽标 + 多个圆盘 → 用户明确否决「重复、难看」。
  本预设的顶栏应改四段方刻度条或非圆形符号。

## S5 · `photo-editorial-haze` 朦胧摄影·编辑（v26）

**适用**：人文 / 柔和 / 真实感优先，用户明确要「朦胧背景、圆形遮罩、镂空蒙版、花瓣、剪影」。

```python
DEEP='#16283C'; PAPER='#F3EFE6'; GOLD='#9A7B45'; GOLD_D='#6E5327'
GOLD_L='#C0A16C'; GOLD_W='#F0E6CE'; WHITE='#FAF7F1'
SOFT='#9AA7B4'; BODY='#333B44'; MUT='#5C626A'; LINE='#DCD5C7'
SMOKE='#25313E'; WARM2='#E9E2D4'
DARK_PAGES = {1,2,3,5,7,8,10,12,13,15}
```

- 素材：圆形柔边遮罩照片 ×3、镂空蒙版、12 片柔边花瓣（只作罗盘底纹）、远山剪影；
- 卡片：柔化偏移阴影，「有填满就无硬边框」；微上浮用 `entrance_rise_up`，嵌套组用静态偏移 + 第二张高 6px；
- 罗盘底盘改半透明烟灰、扇区降饱和、渐变金换纯哑金（宝蓝实心盘 + 渐变高光最像 AI 图标）；
- 删掉「对应评分项 XX 分」与目录卡自曝评分点，换成内容短句。

**已知缺陷（不要重犯）**：
- `head-melt` 浅色渐变盖深底 → 白雾带 / 白扇形，已撤销；
- 圆形遮罩里过曝天空变白斑 → 用 `hi_compress` 亮部 LUT 只压亮部，或裁切避开天空；
- 镂空蒙版方块感 → alpha 206→150、羽化边距 44→70、blur 34→46。

## S6 · `dark-cinematic` 暗场电影感

**适用**：产品发布、科技主题、要求沉浸式深色。
- 深色页占比 ≥ 70%，主件为 96–166 px 巨数或单幅满版摄影；
- 留白 ≥ 40%，一页一句结论；
- 转场用 zoom & pan：同一对象跨页放大 / 平移，`!!Stage` 组 bounds 逐页变化；
- 配色用暖炭墨 `#2C2A26` + 暖白 `#F0E6CE` + 单点铜褐，**不要蓝紫渐层**。

## S7 · `swiss-minimal` 瑞士极简

**适用**：咨询、商务、明确要求「克制 / 少即是多」。
- 无仪式圆盘，用一条进度轨承担导航；
- 严格 12 栏网格、大标题、黑白 + 一点红；
- 全本 fade，不用 Morph 配对；
- 注意：本预设与「惊艳 / 拿第一」诉求冲突，只有用户明确要求克制时才选。

## S8 · `mixed-showstopper` 混合进阶

**适用**：「还要更惊艳」「比上次更强」「长篇多章节」。
- 仪式母题 = 罗盘 + 花瓣放射底纹（花瓣透明度 ≤ 0.20，绝不当主视觉）；
- 内容母题 = 编辑式大版面 + 极淡图纸纹理（网格 0.045）混用，八页八种主件；
- 转场 = Morph 三对象 + 局部 `!!Stage` 深度推进（bounds 从整张画布收缩到半幅，制造镜头推近）；
- 必须至少混合 3 种视觉处理（摄影 / 大字号 / 线性图表 / 遮罩），避免每页同款卡片。

### `!!Stage` 逐页变化示例（15 页）

```python
STAGE_SPEC = {
  1:(0,0,1280,720), 2:(0,0,1280,720), 3:(0,0,1280,720),
  4:(600,214,1216,694), 5:(0,0,1280,720), 6:(64,214,780,694),
  7:(64,214,1216,694), 8:(0,0,1280,720), 9:(560,214,1216,694),
  10:(64,214,1216,694), 11:(64,214,820,694), 12:(0,0,1280,720),
  13:(64,214,1216,694), 14:(500,214,1280,694), 15:(0,0,1280,720),
}
```

仪式页保持整幅，内容页按主件位置左右收缩 → Morph 会做横向镜头推进，观感最丝滑。
