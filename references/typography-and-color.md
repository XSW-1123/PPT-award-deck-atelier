# 字体体系与配色规范

## 1. 字体体系（≤ 2 类 + 1 个数字体）

```python
KAI = 'STXingkai'        # 华文行楷：唯一的大标题 / 仪式章字
WEI = 'STXinwei'         # 华文新魏：副标题 / 岗位名
LI  = 'STLiti'           # 华文隶书：章节小标 / kick
YAO = 'FZYaoTi'          # 方正姚体：结论句 / 页脚注
HEI = 'Microsoft YaHei'  # 正文、标签、表格
GEO = 'Georgia'          # 仅数字、英文、罗马数字
```

### 角色带（超出要在 `spec_lock.md` 的 `## typography` 声明）

| 角色 | 字号 | 字体 | 用法 |
|---|---|---|---|
| 封面主标题 | 120–166 | KAI | 全本只出现一次 |
| 章节章字 | 90–100 | KAI | 四章各一次，重复触发 recurrence 需声明 |
| 内容页标题 | 40–48 | KAI | 每页一次 |
| hero 巨数 | 64–96 | GEO | 一页最多一个 |
| 小标题 / kick | 14–17 | LI / YAO | 可重复 |
| 正文 | 15–18 | HEI | 行距 1.45–1.6 |
| 注脚 / 图签 | 10–12 | HEI / GEO | 对比度仍需 ≥ 4.5:1 |
| 巨型水印 | 180–200 | KAI | 透明度 ≤ 0.05，深色页禁用 |

### 排版硬规则

- **字号 recurrence 门禁**：同一字号在 `--stage final` 下出现 > 2 次，必须在 `spec_lock.md` 的
  `## typography` 里有对应声明，否则 `svg_quality_checker.py` 直接判 error。
  用 `scripts/sync_spec_lock.py` 扫全部 SVG 自动反推补齐，不要手填。
- **Georgia 的下伸部**：`9` 是旧式数字，96 px 时下探约 4–6 px。大数字下方若有副标题，
  基线至少留 18 px 间隙（实测 96 px 大数字在 y=322 结束、副标题基线 326 → 穿字，下移到 340 才干净）。
- **不要用 `txt[:30]` 硬切长文案**：会在行首留下孤立标点（「。第二次更麻烦」）。
  改成语义分好的二元组或手写换行。
- **中文引号统一「」**，英文装饰行能删就删（模板味来源）。
- **贴边半截字**：文字 x 必须距 group bounds 左右边界 ≥ 20 px；实测 x=64/1216 贴边会让首字和状态文字被裁半截，
  内收到 88 / 1176 才干净。用 PIL 扫指定行的暗像素 run 反查真实文字范围，不要靠缩略图肉眼估坐标。

## 2. 三套配色（按预设选，不混用）

### A · 暖中性三色（S1 / S8，默认，2026 去 AI 味首选）

| 用途 | Hex | RGB |
|---|---|---|
| 暖象牙（浅底） | `#F3EFE6` | 243,238,228 |
| 暖炭墨（深底 / 深字） | `#2C2A26` | 44,42,38 |
| 铜褐（唯一强调） | `#9C7746` | 156,119,70 |

辅助：`#6B4E28` 深金（浅底小字）、`#C3A36E` 浅金（深底反白）、`#F0E6CE` 暖白（深底正文）、
`#A8A399` 暖灰（次要字）、`#DCD5C7` 分隔线、`#9E5340` 差距红、`#4A6B52` 达成绿。

**去蓝自检**：把所有 hex 转 RGB，若 `B > R + 8` 计为偏蓝；全本偏蓝数必须为 0。
`patch_v27.py` 曾一次性把 87 处蓝 / 灰蓝 hex 映射成暖中性，这是最省事的换色法——
覆盖模块级常量后，所有沿用旧常量的页面代码自动换色，不必逐页改。

### B · 深蓝金（S2 / S4，仅在用户要庄重蓝金时用）

`#0B2447` 深海军蓝 / `#A87C2E` 金 / `#FBFAF7` 纸白；
辅助 `#D8B267` `#F5E7C4` `#A9C0DC` `#E4E9F0` `#B04A32` `#2C7A5A`。

### C · 低饱和灰蓝 + 哑金（S5 过渡版）

`#16283C` `#25313E` 烟灰玻璃 / `#F3EFE6` 米纸 / `#9A7B45` 哑金；
辅助 `#C0A16C` `#F0E6CE` `#FAF7F1` `#E9E2D4` `#DCD5C7`。

## 3. 用色规则

- 主色 ≤ 3；语义色（红 / 绿）只在「差距 / 达成」出现，不参与配色构成；
- **深色页不超过 7/15**（S1）。整本全深或全蓝底是用户反复投诉的 AI 味来源；
- 卡片「有填满就无硬边框」：实心填充用柔化偏移阴影，描边框只在空卡片用，且描边 ≥ 0.8 px 才看得见；
- 未点亮格子在浅底上不能用 `#D3DCE7`（等于没有），改 `#DCE4EE` + `#AEBED2` 0.8px 描边 + `#BCC9DA` 基线；
- 极淡网格 / 方格：`stroke-opacity` 0.045，只提供秩序感，不能读出图案；
- 深色页**禁止**放大号书法水印（会变成灰墨团），也**禁止**浅色渐变盖深底（漏光）；
- 页脚小色块不要小于 48×3 px，16×3 的小金块在总览里像脏点。

## 4. 对比度与可读性

| 场景 | 要求 |
|---|---|
| 深底正文 | `#F0E6CE` on `#2C2A26`（对比 > 10:1） |
| 深底次要字 | `#A8A399` 0.82 以上不透明度，别用 0.45 |
| 浅底正文 | `#33312D` on `#F3EFE6` |
| 浅底强调小字 | 必须用 `#6B4E28` 深金，不能用 `#C3A36E`（投影会糊） |
| 照片上白字 | 该区域渐变蒙版 `hi` ≥ 0.80；日出等最亮页 0.90 |
| 章节页副标题 | 用 `#F0E6CE` 0.95 / 0.82，别用 `SOFT` / `GOLD_L` 低透明度浅字 |

## 5. 渐变使用边界

允许：烘焙在 JPG 里的方向渐变蒙版；SVG `<defs>` 里低饱和的深底 / 金线 / 卡片渐变。
禁用：蓝紫渐层、大面积亮金→宝蓝渐变、深色底上的浅色渐变过渡、渐变高光做「质感」。
`linearGradient` 里若出现蓝色相，整本 AI 味立刻回来。
